# workdog-portal

업무 포탈(최상위 앱) 프로젝트입니다.

## 목적
- 포탈 내 앱 목록을 조회하고, 개별 업무 앱(예: workdog-archive)으로 연결합니다.
- 초기 연결 정책은 앱을 **새 탭**으로 여는 방식입니다.
- 로그인은 추후 구현 예정이며 현재는 라우트/화면 스텁만 유지합니다.

## 기술 스택
- React
- Vite

## 시작하기
```bash
npm install
npm run dev
```

## 단계 계획
- Phase A: 정보구조/레이아웃/앱목록 연결
- Phase B: 연결 안정화 및 상태 표기
- Phase C+: 접근성/업무형 UI 고도화
